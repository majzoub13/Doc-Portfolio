# ChapterLabel

"CHAPTER 03 — CASE FILE": the publication's running head. `label-chapter` (Barlow 800, 18px, .14em, uppercase) in `text-accent`, led by a 12px ink square with a 2px `comic-red` plate.

## Props
`number` (zero-padded below 10), `title` (optional, in `text-primary`), `prefix` (default "Chapter"; use "Case file" or "File" in project pages).

## Rules
Chapters number the page's main sections in order (01 Intro, 02 Work, 03 Case files, 04 About, 05 Contact). Don't number sub-sections.
