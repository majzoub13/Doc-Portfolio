# Annotation

A technical margin note: a hand-drawn arrow in `decor-annotation` plus `mono-annotation` text (IBM Plex Mono 500, 14px) in `text-technical`, max 32ch.

## Props
`direction`: `left` (arrow points left, default) · `right` · `down`. Children: the note — one short line, facts only.

## Rules
- Annotate evidence (screenshots, diagrams, footage stills), not decoration.
- Place it in the margin beside the frame, overlapping the frame by at most `space-5`. On mobile it drops below the image as a caption-style line (consumer hides the arrow under 480px).
- Max two annotations per image.
