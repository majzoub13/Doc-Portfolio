# Icon

The Doc icon set: 25 line icons on a 24px grid, 2px stroke, square caps, mitred joins, `currentColor`. Also uploaded as single-ink SVGs (ink-black stroke) in the Icons asset group.

## Props
`name` (see the card), `size` (default 24), `title` (makes it a labelled `role="img"`; otherwise `aria-hidden`).

## Sizes
16px inline with mono text · 20px in buttons · 22px in icon buttons and tiles · 24px standalone. Never scale the stroke; never fill.

## Rules
- Ink by default (`text-primary`). Accent colour only to carry meaning (status, technical).
- No brand logos are drawn here. For GitHub, LinkedIn and similar, use the official marks from the brand's own press kit, single-colour, at the same 24px box — or text labels, which `SocialLink` uses by default.
