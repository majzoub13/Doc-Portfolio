# SocialLink

A link to a profile: network name in display caps, optional handle in mono, up-right arrow. Opens in a new tab and says so to screen readers.

## Props
`label` (network name), `handle`, `href`, `variant` (`boxed` default — outlined chip with `shadow-1`; `bare` — text only, for footers), `icon` (optional node for an official brand mark).

Hover (boxed): yellow fill, lift 2px, `shadow-2`. 44px minimum height.
