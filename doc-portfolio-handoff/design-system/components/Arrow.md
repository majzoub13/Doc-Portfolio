# Arrow

Hand-drawn arrows: 3px round-capped strokes, open heads.

## Props
`variant` (`curve` · `loop` · `straight` · `down`), `tone` (`blue` = `decor-annotation`, default · `red` = `decor-burst` · `ink`), `width` (px, default 116), `flip` (mirror).

## Limits
An arrow must point *at* something — a detail in an image, a number, a button — from a note. Blue for technical notes, red for the one thing the reader must not miss, ink for neutral direction. Max two per view.
