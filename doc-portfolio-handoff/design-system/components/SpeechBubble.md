# SpeechBubble

A comic speech bubble for short first-person asides, quotes and testimonials. `radius-bubble` (28px) body, 3px ink border, tail at the bottom, 3px offset drop-shadow.

## Props
`speaker` (mono label: who is talking), `children` (≤ 140 characters), `tail` (`left` default · `right`), `tone` (`paper` · `yellow`).

## Rules
- Quotes must be real and attributed. Never invent a testimonial — if there is none, don't use a bubble.
- Max one bubble per section; never stack bubbles into a dialogue.
- Leave `space-6` below for the tail.
