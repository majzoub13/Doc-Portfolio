# ProjectMeta

The case-file data strip: a `<dl>` of 3–5 facts. Keys in `mono-meta` / `text-technical`, values in `ui` (Inter 500, 15px). A 2px ink rule above, 1px `border-divider` below.

`items`: `{label, value}[]`. Auto-fits columns (min 120px), so it wraps to two columns on phones without a breakpoint.

Use only facts you can stand behind: role, year, stack, type, team size, status. No vanity metrics.
