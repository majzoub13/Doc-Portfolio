# ProjectLinks

The demo / repository / case-study link set, always in this order.

| link | renders |
|---|---|
| `demo` | primary small `Button`, `play` icon (or pass `icon`) |
| `repo` | outline small `Button`, `branch` icon |
| `caseStudy` | `TextLink` |

Each is `{href, label?}`; omit any that don't exist — never link to a private or empty repo. Gap `space-3` × `space-4`; wraps on narrow containers.
