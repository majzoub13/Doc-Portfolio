# Composition

A specimen spread showing how the components sit together — hero line, evidence frame with an overlapping note, chapter panel, callout, meta row — on grained paper. It is a reference for proportion and accent budget, **not** a page design: the portfolio's real layout is a separate task.

## What it demonstrates
- **Accent budget:** red appears as the hero accent line and the frame's plate; yellow once (callout) plus the marker; blue only in technical text. Nothing else is coloured.
- **Overlap rule:** the bubble overlaps the frame by one spacing step (`space-6`), on the bottom-left, and never covers the subject or the caption.
- **Rhythm:** `space-8` section padding, `space-7` between panels, `space-5`/`space-6` inside.
