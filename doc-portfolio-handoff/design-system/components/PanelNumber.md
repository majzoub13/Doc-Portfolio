# PanelNumber

Step and sequence markers: Barlow 800 numeral in an ink disc (`radius-full`) with a 3px `comic-red` plate. `square` for case-file steps, `paper` for outlined markers on ink-heavy areas.

## Props
`children` (the number), `variant` (`round` · `square` · `paper`), `size` (px, default 48; font is half), `label` (aria-label when the number alone is ambiguous).

Use for ordered process steps (pipeline stages, how-I-work) and to number panels on a comic-page layout. Not for counts or badges.
