# Footer

The dark-ink footer: an ink spread (`data-theme="ink"`) with paper grain, a 5px `comic-red` top rule, the large Wordmark with full name and tagline, an "Index" nav column, an "Elsewhere" social column, and a mono base line.

## Props
`tagline`, `nav` (`{label, href}[]`), `socials` (SocialLink props[], rendered `bare`), `legal`, `note`, `brandHref`, `theme` (default `ink`).

## Layout
5 / 4 / 3 columns, padding `space-8` × `space-7`; one column under 760px with `space-6` gaps. Nav links are 22px display caps at 44px row height.
